# fatimasumbul.github.io

My personal website: about me, hobbies, travel and career.

Live at **https://fatimasumbul.github.io**

## How it's organized

| File | What it is | How often I edit it |
|---|---|---|
| `content.js` | All the text, links, photos, trips, hobbies and projects | Often |
| `images/` | Photos used on the site | When adding photos |
| `index.html` | Page layout | Rarely |
| `style.css` | Colors, fonts and design | Rarely |

## How to update the site

1. Open `content.js` on GitHub and click the pencil icon.
2. Change the text, or copy a `{ ... }` block to add a new trip, hobby or project.
3. Click **Commit changes**. The live site updates in about a minute.

To add a photo, upload it to the `images` folder, then set `photo: "images/file-name.jpg"` in `content.js`.

Built with plain HTML, CSS and JavaScript. Hosted on GitHub Pages.
